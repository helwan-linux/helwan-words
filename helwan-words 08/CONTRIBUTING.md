# Contributing to Helwan Words

Thank you for your interest in contributing to **Helwan Words**!

Helwan Words is a multilingual word guessing game developed for **Helwan Linux**. Contributions are welcome, whether you want to add words, improve translations, fix bugs, improve the code, or suggest new ideas.

Every contribution, small or large, can help make the game better.

---

# 🇬🇧 English

## Ways to Contribute

There are several ways you can contribute to Helwan Words:

* Add new words to the word lists.
* Improve or correct existing words.
* Fix bugs.
* Improve the user interface.
* Improve translations.
* Improve the source code.
* Report problems.
* Suggest new features and ideas.
* Improve the documentation.

You do not need to be a programmer to contribute.
**Adding good words to the language files is already a valuable contribution.**

---

## Adding Words

The word lists are stored in the `data/` directory:

```text
data/en.txt
data/ar.txt
data/es.txt
```

Each word must be placed on its own line.

Example:

```text
computer
keyboard
linux
desktop
```

### Important Rules

When adding words:

1. Put only one word on each line.
2. Do not add duplicate words.
3. Use correctly written words.
4. Do not add offensive, abusive, or inappropriate words.
5. Avoid unnecessary names, random strings, or technical terms unless they are useful for the language list.
6. Keep the word lists clean and readable.
7. Use the appropriate language file.

For example:

* English words → `data/en.txt`
* Arabic words → `data/ar.txt`
* Spanish words → `data/es.txt`

---

## Adding Arabic Words

Arabic words should be written normally in Arabic.

Example:

```text
حاسوب
لوحة
كتاب
شمس
قمر
```

Do not add Latin transliterations instead of Arabic words.

---

## Adding Spanish Words

Spanish words should preserve their correct characters and accents.

Examples:

```text
árbol
niño
mañana
corazón
español
```

Characters such as:

```text
á é í ó ú ü ñ
```

are supported.

---

## Code Contributions

If you want to contribute code:

1. Fork the repository.
2. Create a branch for your change.
3. Make your changes.
4. Test the program.
5. Commit your changes with a clear message.
6. Open a Pull Request.

Please keep changes focused and avoid unnecessary restructuring of the project.

---

## Bug Reports

If you find a bug, please report it through the GitHub issue tracker.

When possible, include:

* What happened.
* What you expected to happen.
* Steps to reproduce the problem.
* Your Helwan Linux version.
* Relevant error messages.

Clear bug reports make problems much easier to fix.

---

## Feature Suggestions

New ideas are welcome.

Before proposing a large feature, please consider whether it fits the simple and lightweight nature of Helwan Words.

Suggestions should explain:

* What the feature does.
* Why it would be useful.
* How it could improve the game.

---

## Pull Requests

Before submitting a Pull Request:

* Make sure your changes are intentional.
* Check for duplicate words.
* Check spelling.
* Make sure the program still builds.
* Keep the Pull Request focused on one main purpose.

Small and focused Pull Requests are easier to review and maintain.

---

## Thank You

Thank you for helping improve Helwan Words.

Whether you contribute one word, fix one bug, improve a translation, or contribute a larger change, your contribution is appreciated.

**Helwan Words is built with the help of its community.**

---

---

## إضافة الكلمات

توجد ملفات الكلمات داخل مجلد `data/`:

```text
data/en.txt
data/ar.txt
data/es.txt
```

يجب وضع كل كلمة في سطر مستقل.

مثال:

```text
حاسوب
لوحة
كتاب
شمس
قمر
```

### القواعد المهمة

عند إضافة كلمات:

1. ضع كلمة واحدة فقط في كل سطر.
2. لا تضف كلمات مكررة.
3. استخدم كلمات صحيحة إملائيًا.
4. لا تضف كلمات مسيئة أو غير مناسبة.
5. تجنب الأسماء العشوائية أو السلاسل غير المفهومة.
6. حافظ على نظافة وترتيب ملفات الكلمات.
7. ضع الكلمة في ملف اللغة الصحيح.

مثلًا:

* الكلمات الإنجليزية → `data/en.txt`
* الكلمات العربية → `data/ar.txt`
* الكلمات الإسبانية → `data/es.txt`

# 🇪🇸 Español

## Formas de contribuir

Hay muchas formas de contribuir a Helwan Words:

* Añadir nuevas palabras a las listas.
* Corregir palabras existentes.
* Corregir errores.
* Mejorar la interfaz de usuario.
* Mejorar las traducciones.
* Mejorar el código fuente.
* Informar de problemas.
* Proponer nuevas funciones e ideas.
* Mejorar la documentación.

No necesitas ser programador para contribuir.

**Añadir buenas palabras a los archivos de idiomas ya es una contribución valiosa.**

---

## Añadir palabras

Las listas de palabras se encuentran en el directorio `data/`:

```text
data/en.txt
data/ar.txt
data/es.txt
```

Cada palabra debe estar en una línea independiente.

Ejemplo:

```text
computadora
teclado
linux
escritorio
```

### Reglas importantes

Al añadir palabras:

1. Escribe una sola palabra por línea.
2. No añadas palabras duplicadas.
3. Utiliza palabras correctamente escritas.
4. No añadas palabras ofensivas, abusivas o inapropiadas.
5. Evita nombres innecesarios, cadenas aleatorias o términos técnicos que no sean útiles para la lista.
6. Mantén las listas limpias y fáciles de mantener.
7. Utiliza el archivo correspondiente al idioma.

Por ejemplo:

* Palabras en inglés → `data/en.txt`
* Palabras en árabe → `data/ar.txt`
* Palabras en español → `data/es.txt`

---

## Añadir palabras en árabe

Las palabras árabes deben escribirse normalmente en árabe.

Ejemplo:

```text
حاسوب
لوحة
كتاب
شمس
قمر
```

No añadas transliteraciones en caracteres latinos en lugar de las palabras árabes.

---

## Añadir palabras en español

Las palabras españolas deben conservar sus caracteres y acentos correctos.

Ejemplos:

```text
árbol
niño
mañana
corazón
español
```

Caracteres como:

```text
á é í ó ú ü ñ
```

son compatibles.

---

## Contribuciones de código

Si quieres contribuir con código:

1. Haz un Fork del repositorio.
2. Crea una rama para tu cambio.
3. Realiza las modificaciones.
4. Prueba el programa.
5. Crea un Commit con un mensaje claro.
6. Abre un Pull Request.

Intenta mantener los cambios centrados y evita reorganizar el proyecto sin una necesidad real.

---

## Informar de errores

Si encuentras un error, puedes informarlo mediante GitHub Issues.

Cuando sea posible, incluye:

* Qué ocurrió.
* Qué esperabas que ocurriera.
* Pasos para reproducir el problema.
* La versión de Helwan Linux utilizada.
* Los mensajes de error relevantes.

Los informes claros facilitan mucho la corrección de los problemas.

---

## Sugerencias de funciones

Las nuevas ideas son bienvenidas.

Antes de proponer una función grande, considera si encaja con la naturaleza sencilla y ligera de Helwan Words.

Una propuesta debería explicar:

* Qué hace la función.
* Por qué sería útil.
* Cómo podría mejorar el juego.

---

## Pull Requests

Antes de enviar un Pull Request:

* Asegúrate de que los cambios sean intencionados.
* Comprueba que no haya palabras duplicadas.
* Revisa la ortografía.
* Asegúrate de que el programa todavía se compile correctamente.
* Mantén el Pull Request centrado en un objetivo principal.

Los Pull Requests pequeños y centrados son más fáciles de revisar y mantener.
