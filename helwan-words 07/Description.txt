وظيفة كل جزء
main.c → تشغيل البرنامج وتهيئة GTK.
game.c → كل منطق اللعبة: اختيار الكلمة، الحروف، المحاولات، الفوز والخسارة.
game.h → تعريفات منطق اللعبة.
ui.c → الواجهة والأزرار واللغة وعرض الحالة.
ui.h → تعريفات الواجهة.
data/ar.txt → الكلمات العربية.
data/en.txt → الإنجليزية.
data/es.txt → الإسبانية.
resources/helwan-words.css → شكل الواجهة.
Makefile → البناء.
PKGBUILD → حزمة Arch/Helwan.
.desktop → ظهور اللعبة في قائمة التطبيقات.
README.md → توثيق المشروع.
LICENSE → ترخيص اللعبة.

ومهم جدًا: مش هنعمل مجلدات زيادة لمجرد التنظيم. لو احتجنا ملف جديد فعلًا، نضيفه وقتها.
